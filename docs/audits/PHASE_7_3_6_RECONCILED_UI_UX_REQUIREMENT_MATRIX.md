## Safety decisions

- No backend defect is accepted from screenshots alone.
- Existing prerequisite, route, snapshot, receipt, Pack, projection, import
  recovery and missing-listing services remain authoritative.
- Missing instructions use visible confirmation and optional notes; they are
  not hard-blocked and do not require owner approval.
- One actionable card is scoped to one Order Item ID or ConsignmentLine;
  customer Pack remains package-scoped.
- Scanner lookup never mutates.
- Product Inventory remains catalogue data, not physical inventory.
